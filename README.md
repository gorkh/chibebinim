# چی ببینم؟ 🍿

## ادامهٔ توسعه با عامل کدنویس

نسخهٔ آنلاین فعلی در `cloudflare/bot/` با JavaScript، Cloudflare Workers و D1 اجرا می‌شود. بخش اجرای Python در ادامه مربوط به پیاده‌سازی مستقل قدیمی است و اجرای آن نسخهٔ آنلاین را به‌روزرسانی نمی‌کند.

برای DeepSeek یا هر عامل دیگر، از [AGENTS.md](AGENTS.md) و [HANDOFF.md](HANDOFF.md) شروع کنید. متن آمادهٔ تحویل در [DEEPSEEK_START.md](DEEPSEEK_START.md) است. معماری، تست بدون مصرف سهمیه، روش انتشار و محدودیت‌های شناخته‌شده در راهنمای تحویل ثبت شده‌اند.

ربات فارسی تلگرام برای پیدا کردن فیلم و سریال. از منو می‌شود با انتخاب نوع و ژانر پیشنهاد گرفت، خواسته را به فارسی نوشت، بازخورد ثبت کرد و آثار را برای بعد ذخیره کرد. درخواست هوشمند به فیلترهای ساختاریافته تبدیل می‌شود؛ مشخصات اثر از کاتالوگ می‌آید. پیشنهادها پس از اعمال شرط‌های قطعی و در نظر گرفتن سلیقه مرتب می‌شوند.

## اجرا در ویندوز

از ریشهٔ پروژه و با Python 3.12 یا جدیدتر:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e '.[dev]'
Copy-Item .env.example .env
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\python -m app.main check
```

روی Linux/macOS، به‌جای مسیرهای ویندوز از `.venv/bin/python`، `.venv/bin/alembic` و `.venv/bin/ruff` و به‌جای `Copy-Item` از `cp` استفاده کنید. دستور `check` بدون توکن یا تماس با تلگرام، تنظیمات، دسترسی به شِما، کاتالوگ آفلاین و ساخت dispatcher را بررسی می‌کند.

برای استفاده در تلگرام، از [BotFather](https://t.me/BotFather) توکن بگیرید و در فایل محلی `.env` مقدار `TELEGRAM_BOT_TOKEN` را تنظیم کنید. برای اولین اجرا، کاتالوگ روی `fixture` و AI روی `false` بماند؛ هیچ کلید دیگری لازم نیست.

```powershell
.\.venv\Scripts\python -m app.main
```

گفت‌وگوی خصوصی ربات را باز کنید و `/start` بزنید. دستورها: `/start`، `/menu`، `/recommend`، `/watchlist`، `/profile`، `/help`، `/privacy` و `/cancel`.

## کاتالوگ و AI

- حالت `fixture` از کاتالوگ کوچک محلی در `app/catalog.json` استفاده می‌کند. برای هر عنوان شناسه و لینک مرجع ثبت شده؛ ژانرها برای موتور پیشنهاد یکدست شده‌اند و خلاصه‌های فارسی کوتاه‌اند. امتیاز، پوستر، یا شمار قسمت‌های نامطمئن نمایش داده نمی‌شود. این کاتالوگ برای آزمون جریان‌ها و استفادهٔ محدود است.
- برای TMDB، مقدار `CATALOG_PROVIDER=tmdb` و `TMDB_API_KEY` را تنظیم کنید. کلید v3 یا Read Access Token پذیرفته می‌شود. درخواست‌ها محدود، کش در SQLite پایدار و پیش‌فرض اعتبار کش هفت روز است. هنگام اختلال، همان نتیجهٔ قبلیِ ذخیره‌شده استفاده می‌شود، اگر وجود داشته باشد. شاخهٔ سریال در TMDB بعضی ژانرها را گروه‌بندی می‌کند و دسته‌هایی مانند «ترسناک» فیلم را جداگانه ندارد؛ فیلتر سخت بر اساس دادهٔ قابل‌اثبات اجرا می‌شود و ممکن است نتیجه‌ای ندهد. توضیح آثار در صورت نبود ترجمهٔ فارسی می‌تواند انگلیسی باشد.
- برای AI، `AI_ENABLED=true` و `AI_API_KEY`، `AI_MODEL` و در صورت نیاز `AI_BASE_URL` را تنظیم کنید. مدل باید مسیر OpenAI Chat Completions، حالت JSON و `max_completion_tokens` را پشتیبانی کند. سقف روزانه، زمان انتظار و سقف خروجی در `.env.example` مشخص‌اند. تفسیر محلی برای درخواست‌های واضح در دسترس است؛ برای شرطی که قابل‌استخراج یا اثبات نباشد، ربات درخواست توضیح یا تغییر شرط می‌کند. دلیل پیشنهاد از قالب‌های فارسی و اطلاعات تأییدشده ساخته می‌شود.
- با تغییر منبع کاتالوگ، شناسه‌های آثارِ ذخیره‌شده در منبع قبلی حفظ می‌شوند. تطبیق خودکار آثار بین دو کاتالوگ در این نسخه وجود ندارد.
- دکمهٔ CCloud مستقیم به صفحهٔ اصلی می‌رود. کاربر عنوان را جداگانه کپی می‌کند؛ موجود بودن اثر بررسی نمی‌شود. قابلیت کپی هم دکمهٔ بومی تلگرام و هم پیام مستقل دارد. روی سازگاری‌های قدیمی می‌توان `TELEGRAM_NATIVE_COPY=false` تنظیم کرد.

## Docker و استقرار

نسخهٔ آنلاین ربات از Worker در `cloudflare/bot/` و دیتابیس D1 جداگانه استفاده می‌کند. آدرس سلامت `https://chibebin-bot.raeimohsen.workers.dev/health` است. برای این نسخه، Telegram با webhook درخواست‌ها را به Worker می‌فرستد. هم‌زمان با webhook، همین توکن را در اجرای محلی یا Docker استفاده نکنید. پیش از جابه‌جایی دوباره، از دیتابیس فعال نسخهٔ پشتیبان بگیرید تا تغییرات بعد از انتقال حفظ شوند.

تنظیمات استقرار در `cloudflare/bot/wrangler.jsonc` و طرح دیتابیس در `cloudflare/bot/schema.sql` هستند. سه Secret ابری `BOT_TOKEN`، `TMDB_READ_TOKEN` و `WEBHOOK_SECRET` در تنظیمات خود Worker نگهداری می‌شوند. فایل‌های خروجی انتقال SQLite در پوشهٔ خصوصی و نادیده‌گرفته‌شدهٔ `data/` می‌مانند. مسیر هوشمند Worker از Workers AI برای تفسیر درخواست و از TMDB برای بررسی اطلاعات استفاده می‌کند؛ جزئیات نسخهٔ فعال در HANDOFF.md آمده است.

پس از ایجاد `.env`، با نصب Docker و Compose:

```sh
docker compose config --quiet
docker compose build
docker compose up -d
docker compose logs -f bot
docker compose exec bot python -m app.main analytics
```

کانتینر قبل از polling مهاجرت را اجرا می‌کند. دیتابیس در volume با نام `bot-data` نگهداری می‌شود و سرویس سیاست راه‌اندازی مجدد دارد. برای هر توکن فقط یک poller اجرا شود. پیش از به‌روزرسانی، از SQLite با روش SQLite Backup یا در حالت توقف سرویس نسخهٔ پشتیبان بگیرید؛ حذف volume باعث از دست رفتن داده می‌شود. برای بررسی توقف و شروع، `docker compose restart bot` کافی است.

برای TMDB، «راهنما ← منبع اطلاعات» نشان رسمی و متن انتساب را نمایش می‌دهد. نشان پیش‌فرض از [صفحهٔ رسمی لوگوهای TMDB](https://www.themoviedb.org/about/logos-attribution) تهیه شده است. پیش از عرضهٔ عمومی، [شرایط استفاده و انتساب TMDB](https://developer.themoviedb.org/docs/faq) و سیاست نگهداری نسخه‌های پشتیبان را بررسی کنید.

## آزمون و بررسی انتشار

```powershell
.\.venv\Scripts\ruff check .
.\.venv\Scripts\ruff format --check .
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\alembic check
.\.venv\Scripts\python -m app.main analytics
```

برای بررسی زنده با توکن معتبر:

1. در تلگرام `/start` بزنید، «پیشنهاد سریع ← فیلم ← کمدی» را انتخاب کنید و پیشنهاد بعدی را بگیرید.
2. روی کارت بازخورد ثبت کنید، آن را به فهرست اضافه کنید و از `/watchlist` جزئیات را باز کنید. ربات را متوقف و دوباره اجرا کنید و باقی ماندن فهرست و سلیقه را بررسی کنید.
3. در انتخاب هوشمند «یه فیلم هیجان‌انگیز زیر دو ساعت» یا «یه سریال شبیه Dark» بفرستید. اگر کلید AI و TMDB دارید، هرکدام را جدا فعال کنید و همین مسیر را تکرار کنید.
4. کپی عنوان و باز شدن صفحهٔ اصلی CCloud را در کلاینت واقعی تلگرام بررسی کنید. در یک حساب آزمایشی، حذف داده را از تنظیمات تأیید کنید.

گزارش CLI تعداد کاربران، فعالیت تقریبی روزانه و هفتگی، جلسه‌ها، تعامل‌ها و مصرف گزارش‌شدهٔ AI را نمایش می‌دهد. نرخ بازگشت، نسبت کاربرانی با آخرین فعالیت دست‌کم هفت روز پس از ثبت‌نام است. [Bot API تلگرام](https://core.telegram.org/bots/api#inlinekeyboardbutton) کلیک روی دکمهٔ URL یا کپی بومی را به ربات گزارش نمی‌کند؛ کلیک CCloud با لینک مستقیم قابل‌اندازه‌گیری نیست. فقط درخواست نمایش عنوان برای کپی به‌صورت رویداد ثبت می‌شود.

## ساختار و داده‌ها

`app/bot.py` ورودی تلگرام را مدیریت می‌کند؛ `app/service.py` جریان پیشنهاد، بازخورد و مالکیت را؛ `app/recommend.py` شرط‌های قطعی و رتبه‌بندی را؛ `app/catalog.py` و `app/parser.py` اتصال‌های اختیاری و جایگزین‌های آفلاین را. شِما و مهاجرت در `app/db.py` و `migrations/` قرار دارند. SQLite برای استقرار تک‌پردازشی است.

متن خام درخواست نگهداری نمی‌شود. بخش انتخاب‌های گفت‌وگو هنگام راه‌اندازی مجدد از نو آغاز می‌شود؛ فهرست، سابقه، سلیقه و صف‌های معتبر پیشنهاد در دیتابیس می‌مانند. «تنظیم مجدد سلیقه» لایک و دیسلایک را پاک می‌کند و فهرست و وضعیت تماشا را نگه می‌دارد. «حذف اطلاعات من» پس از تأیید، دادهٔ قابل‌انتساب در دیتابیس فعال را حذف می‌کند. داده‌های عمومی کاتالوگ و آمار فنی بی‌نام باقی می‌مانند.
